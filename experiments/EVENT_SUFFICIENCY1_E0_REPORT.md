не-success) — все 4 механики:

## 3. Выводы (журнальные, без интерпретации сверх данных)

1. **Журнал STALE-EXACT-1 не содержит ни одного реалистичного
   noise-эпизода**: шум моделировался синтетически (прямая запись
   result с sb==sa, 1 поле). Его канал беднее канала Executor в 9
   раз — сравнение «полный канал stale vs полный канал noise» по
   имеющимся данным НЕВОЗМОЖНО.
2. Единственное журнальное различие (переход state) тривиально:
   синтетический шум по построению не менял мир; реалистичный
   внешний сбой (мир нетронут, но сервис не поднялся) дал бы тот
   же переход, что stale: `inactive -> failed`, симптом `a -> none`
   (флаги сняты fix-a, скрытая причина осталась). Гипотеза E0
   (неразличимость по полному каналу) этим журналом НЕ проверена и
   НЕ опровергнута.
3. **E0-вывод требует одного целевого прогона** (политика: шум как
   скрытый флаг `n`, НЕ снимаемый fix-a и НЕ видимый симптомом;

   v0.3/F0, без declare, без exploration — только запись фактов;
   серии: stale ×N и noise-real ×N). Ожидание (гипотеза): полные
   каналы двух классов идентичны → информационная граница
   подтверждается на первом эпизоде.
