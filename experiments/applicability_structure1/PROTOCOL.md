# APPLICABILITY-STRUCTURE-1: PROTOCOL (FROZEN 06.09.2026)

Дизайн: APPLICABILITY_STRUCTURE1_DESIGN.md (frozen). Измерительный;
v0.5 и слои НЕ изменяются; measurement-only (регистратор);
стоп-решения вычисляются в анализе, контуром не исполняются.

**Миры (политика драйвера; фиксирована ДО прогона):**
w1=[a] E=absent V='1' | w2=[a,extra] E=present V='2' |
wX=[a,extra] E=present V='1' | wY=[a] E=absent V='2' |
noise=[a,n] E=absent V='1'. envver-файл пишется драйвером
независимо от lock-флагов (расхождение конструируется).

**Процедура:** learn fix-a в w1 (фиксация эталона: E_learn=absent,
V_learn='1', S_learn='a') на каждой реплике; затем эпизоды:
w1×2, w2×3, wX×3, wY×3, noise×3; реплики r1, r2 (2 стора).
Эпизод: env → чтение сигналов ДО действия (E,V,S) →
фиксированное fix-a через Executor → outcome; опыт/знания не
создаются. Ground truth применимости по миру:
GT = (w1|wY|noise)=true, (w2|wX)=false (контроль: фактический
outcome эпизода).

**Композиции (офлайн):** C1={E}, C2={V}, C3={E∧V}, C4={E∧V}+
вектор расхождения (dE,dV): dX = сигнал_now != сигнал_learn;
C5={E∧V∧S}. Стоп = любой член отклонён от эталона.

**Метрики по миру × композиция:** верный стоп (стоп ∧ GT=false),
ложный стоп (стоп ∧ GT=true), слепота (не-стоп ∧ GT=false),
верное применение (не-стоп ∧ GT=true); доли по эпизодам, обе
реплики.

**Предсказания дизайнера (сравнить с измерением, не подгонять):**
C1: ошибок 0 во всех мирах (E физически отражает extra);
C2: слепота в wX (V='1', физика сменилась), ложный стоп в wY
(V='2', физика не менялась);
C3: как C2 в wY (ложный стоп), верный стоп в wX (E-член);
C5: ≡ C3 (S не отклоняется нигде — избыточность без потерь);
C4-вектор: (dE,dV): w1/noise=(0,0), w2=(1,1), wX=(1,0), wY=(0,1)
— различает все миры; причину «кто прав» по паре сигналов не
восстанавливает (нужны последствия/третий источник).

**Порядок анализа:** RAW → поведение условий по мирам → верные/
ложные стопы/слепота → сравнение с предсказаниями → A/B/C.

**Запреты:** без trust; без новых правил в Strategy; без вывода
«wX/wY — один класс» без проверки значений сигналов; без
изменений v0.5/слоёв. Политика мира (envver независимо) — часть
заморозки.

Артефакты: as2_driver.py, AS2_run.log, AS2_records.json,
as2_analyze.py, AS2_ANALYSIS.txt, APPLICABILITY_STRUCTURE1_REPORT.md.
