# TSARAPINA APPLICABILITY-SIGNAL-1: DESIGN (06.09.2026)

**Статус: ДИЗАЙН (профессор). Протокол и запуск — по слову; код за
воротами; v0.5 не изменяется (measurement-only, как CS-1).**

## 1. Вопрос

CS-1 (PASS A+B) установил: достаточен класс до-действенных
наблюдаемых фактов среды вне symptom-канала, соединимых с
applicability structure. Открытый вопрос:

> Какие ХАРАКТЕРИСТИКИ наблюдаемого факта делают его пригодным
> как условие применимости знания?

Это вопрос о КЛАССЕ ПРИЗНАКОВ (структуре сигнала), а не о
количестве данных/сенсоров. Ответ должен дать правило отбора:
какой факт стоит фиксировать в условиях знания при обучении, а
какой — шум/ловушка (ложные факты дороже их отсутствия — они
создают ложную адресацию).

## 2. Семь свойств сигнала (гипотеза-факторизация)

Пригодный факт F (наблюдаемое значение перед действием):

1. **СВЯЗАН С ПРИМЕНИМОСТЬЮ**: его значение детерминировано
   состоянием мира, определяющим применимость (не произвольный
   декоративный факт);
2. **ДОСТУПЕН ДО ДЕЙСТВИЯ**: читается Observer до выбора/действия
   (не consequence-производный);
3. **НЕ ЗАВИСИТ ОТ РЕЗУЛЬТАТА ДЕЙСТВИЯ**: его изменение не вызвано
   самим действием (иначе цикл: факт меняется потому, что мы
   действовали);
4. **НЕ ДУБЛИКАТ СУЩЕСТВУЮЩЕГО КАНАЛА**: несёт информацию, которой
   нет в symptom-канале и в других уже адресуемых фактах (иначе
   нулевой вклад в адрес);
5. **СТАБИЛЕН В ПРЕДЕЛАХ СОСТОЯНИЯ**: не флуктуирует между
   наблюдениями одного и того же состояния (иначе адрес знания
   дрожит);
6. **МЕНЯЕТСЯ ПРИ РЕАЛЬНОЙ СМЕНЕ ПРИМЕНИМОСТИ И ТОЛЬКО ПРИ НЕЙ**:
   на траекториях: изменение F ⇔ структурная смена применимости
   (иначе: ложный сигнал на шуме — FP; или пропуск смены — FN);
7. **ВЫРАЗИМ КАК УСЛОВИЕ ЗНАНИЯ**: дискретное/сравнимое значение,
   представимое в applicable_when (равенство/наличие); непрерывные
   значения — только с порогом (порог = RESEARCHABLE, в MVP не
   вводить).

## 3. Кандидаты (наблюдаемые факты полигона)

| id | факт | сенсор | ожидаемая пригодность |
|----|------|--------|----------------------|
| E | lock.extra present/absent | envfact | ПРИГОДЕН (эталон CS-1) |
| V | /run/tsasvc.envver 1/2 | envver | ПРИГОДЕН (внешний маркер смены) |
| N | lock.n present/absent (наблюдаем только здесь) | прямое чтение | НЕПРИГОДЕН: меняется при шуме без смены применимости (FP) — свойство 6 |
| D | /run/tsasvc.dbg (демон игнорирует; произвольный) | файл | НЕПРИГОДЕН: не связан с применимостью (свойство 1); меняется произвольно (6) |
| P | /run/tsasvc.pulse (перезапись каждые 2с) | файл | НЕПРИГОДЕН: нестабилен в пределах состояния (свойство 5) |
| S | symptom (a) | symptom | НЕПРИГОДЕН как доп. условие: дубликат канала (свойство 4) |
| L | cpu.load1 | loadavg | ОСОБЫЙ: непрерывный — выразим только с порогом (свойство 7); RESEARCHABLE |

Политика: N/D/P наблюдаются ТОЛЬКО в этом измерении
(measurement-only; в контур не вводятся); демон не читает dbg/pulse
(dbg — НЕ lock-файл: демон падает при любом lock.*, поэтому dbg —
отдельный файл /run/tsasvc.dbg; pulse — /run/tsasvc.pulse).

## 4. Серии (ground truth: применимость fix-a — лечит ли мир)

Каждая серия — последовательность эпизодов (регистратор: действие
не управляется; запись значений ВСЕХ кандидатов до действия +
применимость по миру):

- C1 стабильный мир: w1 ×8 (применимость истинна всю серию);
- C2 смена применимости: w1 ×3 → w2 (a+extra) ×5 (смена на эп.4;
  extra/version меняются; n/dbg/pulse — нет);
- C3 внешний шум: w1 ×3 → noise (a+n) ×1 → w1 ×3 → noise ×1
  (применимость структурно НЕ меняется; n меняется при noise;
  extra/version — нет);
- C4 декоративный факт: w1 ×2 → (a + dbg-файл) ×3 → w1 ×3
  (применимость не меняется; dbg меняется);
- C5 (для P): w1 ×6, pulse читается дважды внутри эпизодов
  (флуктуация при том же состоянии).

Каждая серия: ×2 повтора (r1/r2). Эпизоды — через Executor.

## 5. Метрики

Для каждого кандидата F по всем сериям/повторам: бинарная
траектория значения (изменилось относительно обучения или нет)
против бинарной траектории применимости:
- FP: F изменился при НЕизменной применимости (C1/C3/C4/C5);
- FN: F не изменился при смене применимости (C2);
- согласованность: доля эпизодов с (F_изм == примен_изм).
Пригоден: FP=0, FN=0, согласованность 1.0, свойства 1–5, 7 по
таблице.

**Ожидания (гипотезы):** E и V: FP=0, FN=0 (пригодны, 7/7); N:
FP>0 на C3 (ложный сигнал шума); D: FP>0 на C4; P: флуктуации
внутри состояния; S: нулевой вклад (дубликат); L: вне MVP-класса.

## 6. Исходы

- (A) E/V пригодны, ложные кандидаты отсеяны ровно по
  предсказанным свойствам → класс пригодности подтверждён: правило
  отбора фактов для условий применимости; следующий шаг — обучение
  условиям (какие факты фиксировать при learn — по свойствам);
- (B) ложный кандидат проходит или эталон проваливается → свойство
  не различает классы (пересмотр факторизации);
- (C) эталон нестабилен на повторах → проблема измерения.
