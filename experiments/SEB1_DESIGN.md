# TSARAPINA SEB-1 (STRATEGY/EXPLORATION BOUNDARY): ДИЗАЙН (06.09.2026)

**Статус: ЗАМОРОЖЕН профессором 06.09.2026 → запуск разрешён.**
Код: experiments/seb1/. Три контрольные точки: (а) известный +
применимый → S2 1 действие; (б) известный + неприменимый → SEB-1
объект → exploration?; (в) неизвестный → exploration → fix-c →
последующие S2. M2 exact gate — только маршрутизация, НЕ
обобщение: «есть ли точное применимое знание?» Если нет — право
искать, НЕ право знать, что искать. Первый C-эпизод: exact ∅ →
broad hypothesis → не-success → systematic exploration → fix-c →
устойчивый success; последующие: exact → S2 → fix-c (приобретение
через прямое последствие). return-A обязан остаться 1 action
(иначе FAIL-регрессии на фоне TRUST-1). После полного прогона —
сначала сырые траектории, затем вердикт.

## 1. Вопрос (дословно, профессор)

> Может ли стратегия обнаружить собственную недостаточность
> применения известного знания и уступить место поиску, не
> разрушив уже подтверждённую эффективность S2 на знакомых
> классах?

Три события, которые стратегия должна различать:
```
1. правильное знание есть      → применить его      (S2 exploit)
2. знание есть, но неприменимо → исследовать        (SEB-объект)
3. знания нет                  → исследовать        (S1 уже умеет)
```
Сейчас: 1 — хорошо (зоны 1–4), 3 — через S1, 2 — НЕ различается
(GENERALIZATION-1: broad-релевантное fix-ab применялось 7/7 к C).

## 2. Контекст (что установлено и НЕ трогается)

- S2 (exploit) на знакомых классах: 1 действие, success — эталон
  эффективности (VERTICAL-1 v2, LONGITUDINAL-1, G1-Ф1);
- R1 (symptom-exact) заморожен; Knowledge/Update/Evaluation не
  меняются; aggregation — explicit-инструмент;
- C-провал G1: у задачи симптом c, exact-пула НЕТ (знаний с
  symptom=c нет); pool = broad (общие токены задачи) → S2
  применяет broad-знание как эксплуатацию и повторяет его
  (recency) — поиск подавлен;
- зона 3-урок: без причинного слоя «действие неприменимо»
  неотличимо от «мир изменился/шум» — различитель обязан НЕ
  ломать устойчивость к шуму на знакомых классах (S4-сценарий:
  s,f,s → возврат к fix-a);
- урок G1-контроля: критерий успеха эпизода — УСТОЙЧИВОЕ состояние
  (active через 2с), не мгновенное.

## 3. Что НЕ строим заранее (запреты)

🔴 НЕ объявляем правильной эвристику «после N failure — открыть
поиск» (профессор: это решение, которое надо ПРОВЕРЯТЬ);
🔴 никаких правил переноса/обобщения (зона 4 закрыта: знание
C→action возникает только из проверенного последствия C);
🔴 broad-применение НЕ получает статус знания: если стратегия
пробует broad-действие — это ГИПОТЕЗА (одна проверка, помеченная
hypothesis), а не S2-эксплуатация;
🔴 не менять Knowledge/Update/R1/Executor/полигон;
🔴 exploration — только систематический перебор разрешённых
команд (allowlist, фиксированный порядок, без LLM-планирования);
🔴 без причинного слоя; без trust-чисел; 🔴 интерпретация — после
полного прогона.

## 4. Механики-кандидаты (факторно, как T1–T3 в зоне 3)

Ветка: strategy_v4 (в experiments/seb1/); основная Strategy v0.2
не меняется. Каждая механика — ГИПОТЕЗА для проверки:

- **M0 — контроль**: поведение v0.2 (C: broad → S2 fix-ab ×7,
  поиск подавлен; a/b/ab: S2 1 действие).
- **M1 — local repeat ban**: в рамках ОДНОГО эпизода действие X,
  уже давшее проверенный не-success на этом симптоме, не
  предлагается повторно; при исчерпании кандидатов — S1
  (наблюдение). Не «после N failure — поиск»: запрет только на
  повтор доказанно-неуспешного действия в том же эпизоде.
- **M2 — exact gate**: если задача несёт симптом и exact-пул
  ПУСТ → broad-знания не применяются как эксплуатация: (а) одно
  broad-действие допускается как ГИПОТЕЗА (свежайшее релевантное,
  помечено hypothesis, 1 действие); (б) при не-success →
  EXPLORATION: систематический перебор разрешённых команд
  (фиксированный порядок allowlist) с устойчивой проверкой после
  каждой; до success (max-шагов); (в) после success — обычный
  update: знание C→action создаётся ИЗ ПРОВЕРЕННОГО ПОСЛЕДСТВИЯ
  (не из гипотезы). Знакомые классы (exact есть) — M2 не
  вмешивается: S2 как был.
- **M3 = M1 + M2**: комбинация.

Проверочные сценарии (каждая механика на чистом сторе, полигон
tsasvc):
- S-a/b/ab: знакомые классы после learn: S2 → 1 действие
  (регрессия exploit: должно остаться 1/1);
- S-return-A: возврат A после B (ядро R1): 1 действие (регрессия);
- S-noise: знакомый A: s, f(шум), s → задача: fix-a снова
  (устойчивость к шуму НЕ ломается — различитель не должен
  уводить exact-класс в exploration);
- S-C (новый класс, без learn): 7 эпизодов: первый эпизод —
  достигается ли fix-c (M2: гипотеза + перебор ≈ 6 действий),
  последующие — S2 1 действие (знание C создано последствием);
  M0: 0/7 (эталон провала);
- S-C-noise: новый класс c с шумом в первом успехе? (после
  exploration-успеха fix-c: знание; далее exact) — контроль
  создания знания;
- swap qwen25 (C-эпизод): независимость.

## 5. Метрики

- M1-exploit: действия до success на a/b/ab и return-A (эталон 1;
  регрессия = механика разрушила S2);
- M2-новый класс: первый C-эпизод: actions_to_success (или «не
  решён»); эпизоды 2–7: actions (эталон после знания: 1);
- M3-детекция события 2: доля C-эпизодов, где после не-success
  broad-применения стратегия открыла поиск (не повторила то же);
- M4-цена поиска: действия exploration на C vs перебор-baseline
  (6); M5 история/версии целы; M6 детерминизм; M7 swap;
- аудит знания: знание (c → fix-c) создано ТОЛЬКО после
  проверенного success fix-c (нет знания-до-опыта).

## 6. Исходы (фиксируются заранее)

- **PASS**: есть механика, на которой: (1) знакомые классы и
  return-A — 1 действие (S2 не разрушен); (2) шум на знакомом не
  уводит в exploration; (3) C: первый эпизод достигает fix-c
  (поиск открыт после не-success broad), эпизоды 2–7 — S2 1
  действие; (4) знание C создано последствием; (5) история цела,
  детерминизм; (6) swap.
- **PARTIAL**: C решается, но ценой регрессии на знакомых/шуме
  (граница различителя).
- **FAIL/граница**: различение события 2 требует сигнала,
  отсутствующего у контура (причинный слой/внешняя стоимость) —
  вывод: «стратегия не может обнаружить собственную
  недостаточность применения знания без нового сигнала; цена
  различения = цена проб; S1 остаётся единственным честным
  путём для нового класса» (полноценный отрицательный результат
  с точной границей).
