# TSARAPINA STALE-EXACT-2 (ADDRESS-MATCH): ОТЧЁТ (06.09.2026)

Дизайн: STALE_EXACT2_DESIGN.md (FROZEN). База: Strategy v0.4
(основная; НЕ изменялась). Полигонные правки задокументированы:

эксперимента). Порядок соблюдён: сырые траектории → E2b → E2c/E4.

## 1. Сырые траектории (E2a: поведение v0.4 в B)

```
S-OK  s s s s s s          (эталон: w1, 1 действие success)
N     s s f s s s          (noise-real: единичный шум пережит
                            ценой 1 лишнего действия)
ST    f f f f f f          (w2 без learn: ЗАСТРЕВАНИЕ, S2 fix-a
                            каждый раз; адрес совпадает — v0.4 не
                            имеет пути для B)
ST-L  f f f [learn fix-aq] s   (выход ТОЛЬКО через learn; затем
                            S2 fix-aq, 1 действие)
S2    s s f f f f          (смена после 2 успехов)
LATE  s s s s f f f        (поздняя смена)
ALT   s f s s f s          (единичные шумы; без f,f)
MIX   s f s f f f          (шумовая история, затем смена)
```
Во всех w2-эпизодах: strategy=S2, rule=known_fix, cmd=fix-a —
адрес (a, absent) совпадает, eligible один; застревание
неограниченно (ST: 6 эпизодов без выхода).

## 2. E2b: информационная граница B при v0.4

Сравнение полных каналов первого не-success: stale (st_1, w2) vs
noise-real (no_f1, w1+n): адресная строка идентична (symptom=a,
ctx=absent). Различия — ТОЛЬКО плавающие/окружение: cpu.load1,
memory, process:sshd.count, disk.free_kb. Внутриклассовый контроль:
те же поля расходятся внутри stale (st_1 vs st_2) и внутри noise
(no_f1 vs ca_f1_1) — набор различий не зависит от класса.
**Стабильных класс-различий НЕТ: v0.4 не создал нового
наблюдаемого пути для B; граница первого эпизода подтверждена
повторно (адрес не заменяет наблюдение).**

## 3. E2c/E4: темпоральное измерение (индикатор «2 подряд
не-success»; зафиксирован ДО подсчёта)

- первых не-success после успешного хвоста (неразличимы на 1-м
  эпизоде): 9;
- срабатываний индикатора: 9 — ВСЕ в w2-фазах (после смены мира
  w1→w2): S2@5, S2@6, LATE@7, MIX@6, ST@3..6; на чисто шумовых
  сериях (N, ALT): 0 срабатываний (ложных: 0);
- прогноз следующего исхода: верно 4/4 на сериях без вмешательства
  (S2@5→f, ST@3→f, ST@4→f, ST@5→f); 1 «промах» — learn-
  вмешательство (ST-L: после f,f,f оператор показал fix-aq,
  следующий эпизод s — индикатор не знал о вмешательстве);
  промахов на шуме: 0;
- ни одно срабатывание не приходится на ПЕРВЫЙ f после смены мира:
  все — на 2-м подряд (задержка сигнала = 1 эпизод).

## 4. Вердикт (по критериям дизайна)

1. v0.4 в B застревает (ST: 6/6 f, S2-повтор) и выходит только
   через learn (ST-L) — «адрес решил A (S3 context_mismatch);
   B адресом НЕ решается» — подтверждено;
2. E2b: каналы первого последствия B-stale/B-noise идентичны по
   стабильным полям (с адресом; внутриклассовый контроль чист) —
   информационная граница первого эпизода для B подтверждена при
   v0.4: applicability addressing решает различие условий, КОГДА
   условия представлены в адресе; изменение применимости за
   пределами наблюдаемого адреса не обнаруживается;
3. E2c: темпоральный сигнал существует и измерен: «второй подряд
   не-success» встречается только после смены мира (0 ложных на
   шумовых сериях); прогноз 4/4 без вмешательства; первый f после
   смены неразличим (9 случаев, ни одного срабатывания) —
   зафиксировано КАК ИЗМЕРЕНИЕ (механизм — не сейчас: запрет
   дизайна на N-счётчики/авто-failure→exploration; кандидат-событие
   задокументирован для будущего отдельного дизайна);
4. E4: ложных срабатываний на шумовых сериях 0; единственный
   промах индикатора — внешнее learn-вмешательство (класс промаха
   зафиксирован отдельно от шума).

**Формулировка результата:** при совпадении (symptom, context) с
адресом проверенного знания v0.4 не обнаруживает изменение
применимости ни в одном наблюдаемом канале первого последствия
(E2b); поведение — неограниченный слепой повтор (E2a); исторический
сигнал появляется на втором подряд не-success и на шумовых сериях
не срабатывает (E2c/E4) — измерение, не механизм. Предсказание
дизайнера подтвердилось фактической веткой; отклонений нет.
