# TSARAPINA CHANNEL-SUFFICIENCY-1: DESIGN (06.09.2026)

**Статус: ДИЗАЙН — ЗАМОРОЖЕН (профессор). Измерительная зона.
Strategy v0.5 НЕ ТРОГАЕТСЯ; код за воротами; прогон — по слову.**

## 1. Вопрос

> Какой дополнительный наблюдаемый канал делает смену применимости
> различимой, если канал последствий сам по себе недостаточен?

Контекст: SUFFICIENCY-2 (A+C / B rejected) — история последствий —
канал о смене условий, но достаточность зависит от фонового
процесса; при неразличимом фоне канал последствий не позволяет
безопасно локализовать смену. Стратегия НЕ лечится: информационный
дефицит не лечится новым `if`.

## 2. Принцип измерения (все F — measurement-only)

```
RAW → CHANNEL → SEPARABILITY
```
- сначала сырые трассы (raw traces);
- затем измерение separability классов STALE / NOISE по каналу;
- только после этого интерпретация;
- переходы НЕ исполняются; никаких `if channel_changed: explore()` —
  сначала измерение, потом (отдельно, по слову) решение о
  механизме.

В каждой серии: STALE и NOISE, одинаковые (symptom, context,
command), одинаковое начальное Knowledge, одинаковый Executor,
одинаковая v0.5.

## 3. Матрица

```
Серия | Consequence | Env fact | Applicability | External | Что проверяем
F0    |     ✓       |    ✗     |      ✗        |    ✗    | текущая граница
F1    |     ✓       |    ✓     |      ✗        |    ✗    | новый факт
F2    |     ✓       |    ✗     |      ✓        |    ✗    | структура применимости
F3    |     ✓       |    ✗     |      ✗        |    ✓    | независимый канал
```

### F0. Контроль (текущий канал v0.5)
`Observer → symptom/context → action → consequence`.
Сценарий воспроизводит STALE-EXACT-2: адрес знания остаётся тем же
((symptom=a, ctx=absent)), скрытое условие меняется (w2: a+q; q не
виден ни symptom-каналу, ни ctx). Ожидание: контур не различает
stale/noise (граница воспроизведена) — контроль корректности
измерительной установки.

### F1. Environment delta (новый наблюдаемый факт среды)
Добавляется наблюдаемый факт среды, который:
- не является симптомом;
- не зависит от результата действия;
- не содержит подсказки `stale=true`;
- появляется при смене мира; отсутствует в старом мире.

Пример: `ctx_extra = absent` → после перехода `ctx_extra = present`.
ВАЖНО: сырой environmental fact (факт мира, читаемый сенсором), НЕ
сконструированный флаг состояния знания. Проверка: `world change →
fact change` ДО первого действия. Если stale/noise разделяются уже
здесь — причина информационная: канал существует.

### F2. Applicability structure (условия применимости в знании)
Не сообщает напрямую, что мир изменился; расширяет описание
условий применимости действия:

```
Knowledge: action = fix-a
           applicable_when:
               lock.a = present
               extra  = absent
```
Новый мир наблюдаем как: `lock.a = present, extra = present` →
возникает проверяемое отношение:
`current_state ⊭ applicability_conditions(K)`.
Ключевой тест: можно ли получить различимость из СТРУКТУРЫ
применимости, не вводя trust, causal model или заранее заданное
stale-правило?

### F3. External channel (независимый источник)
Класс специально отделён от Observer→consequence: независимый
источник сообщает собственный факт (не «знание устарело»):
`source_B: environment_version = 2` (или изменение внешнего
состояния). Интересует принцип: независимый канал может сделать
два ранее неразличимых состояния различимыми.

### F1 ≠ F2 (не смешивать)
- F1: МИР сообщает дополнительный факт — вопрос «есть ли
  недостающая информация?»;
- F2: ЗНАНИЕ содержит условия, относительно которых можно
  адресовать факт — вопрос «может ли представление знания
  использовать его структурно?».

## 4. Критерии separability (жёстче, чем «появилась разница»)

1. До первого действия канал различает STALE/NOISE или нет
   (измерение ДО consequence).
2. Различимость сохраняется при повторениях (серии ×N, не единичный
   случай).
3. Канал не является просто переименованным `stale` (содержательный
   факт, не метка класса).
4. Не зависит от результата действия (не consequence-производный).
5. Не требует заранее знать t0 (факт доступен в момент наблюдения).
6. Его наличие не ломает старые свойства v0.5 (регрессия-проверка).

## 5. Исходы

- **A.** F1/F2/F3 дают separability → текущая проблема была
  информационной: дополнительный канал делает состояния
  различимыми.
- **B.** Только определённый КЛАСС каналов работает (например:
  environmental fact работает, applicability structure без него не
  добавляет информации) → узнаём не «нужен ещё канал», а какой ТИП
  информации достаточен.
- **C.** Даже дополнительные каналы не дают устойчивой separability
  → граница глубже: проблема не в бедности текущего Observer, а в
  невозможности определить применимость из доступного
  представления состояния.
