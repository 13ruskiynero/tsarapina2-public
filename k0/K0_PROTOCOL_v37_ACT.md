## 2. Изменение (реализовано)

1) **Внедрение пригодной цели.** После первого исполненного блока `DECISION`
   (в той же итерации F2, до сборки следующего промпта) регистрируются **Q2/H2**:
   клетка **`O4 T=2 H=1`**, прогноз **`present`**, REF `t07`,
   **`origin=driver`**. Пригодность проверяется **по префиксу состояния**
   (мир + реестр проб): объект `present`; раскрытых проб клетки нет. При
   непригодности — запись `goal(eligible=false, reason=…)`, внедрения нет
   (критерий → неинформативен).
2) **Видимость цели:** секция **`[ГИПОТЕЗЫ]`** в F2-промпте — рендер состояния
   реестра («H1: клетка …, прогноз … — вердикт: refuted (V1). H2: клетка …,
   прогноз … — открыта.»). Слов действия в секции нет (тест T2 + лексикон);
   грамматика/валидатор не меняются.
3) **Журнал:** поле `call` во всех записях; запись `goal` (`cell`, `prediction`,
   `q`, `h`, `eligible`, `reason`; `origin=driver`); §11 — новый тип.
4) **Метки:** `protocol_version = v37`, `RUN_NAME = run_K0-M3_104_v37`.
