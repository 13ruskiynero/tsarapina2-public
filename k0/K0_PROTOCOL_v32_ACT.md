# K0 — АКТ v32: проба по клетке зарегистрированной H1 (инструкция из записи гипотезы)

Дата: 2026-10-16 · Подготовил: DeepSeek TUI · Для постановщика K0 и внешней проверки
Статус: **v32 подготовлен; проверки пройдены; публикуется ДО запуска.
Запуск НЕ ВЫПОЛНЕН и будет выполнен только по отдельному решению после ревью
(без автоперезапусков).** v26–v31 и их артефакты — заморожены.

## 1. Основание

- Решение по v31: «v31 фиксируем как частичный технический успех и замораживаем.
  Новый прогон сейчас не разрешаю»; «следующий шаг — подготовить проект v32, но не
  запускать модель»: проверить, может ли явная инструкция заставить модель выполнить
  пробу именно в клетке уже зарегистрированной H1, опираясь на существующую запись
  гипотезы; механизм вердиктов одновременно не менять; границы — прежние.
- Фиксация v31: `K0_M3_V31_FIXATION.md` (переход подтверждён; соответствие пробы
  гипотезе не достигнуто; вердиктов/решений нет).
- Проект и разбор: `K0_V32_DESIGN_DRAFT.md` (§1–§4).

## 2. Изменение (единственная переменная)

**Секция `[СЛЕДУЮЩИЙ ШАГ]` строится из ЗАПИСИ гипотезы.** Файлы:

- `code/prompts.py` — `F2_NEXT_STEP` становится шаблоном с полями `{label}`,
  `{cell}`, `{pred}`; `build_f2` при `P=0` и наличии гипотез рендерит секцию из
  `ctx.hypotheses[0]` (данные реестра, не текст модели): «Гипотеза H1
  зарегистрирована: клетка …, прогноз …. Повторная регистрация не нужна. Проверь
  именно эту клетку: строка PREDICT: … = …, затем строка ACTION: probe …».
- `code/session.py` — `AgentContext.hypotheses` (для F2): пары «метка, клетка,
  прогноз» из реестра; метки версии `v32` (серия `K0-M3` не меняется).
- `code/calls.py` — `render_context` включает `"hypotheses"` для F2 (вход секции
  виден в JSON-артефакте вызова).

**Служебные приведения (не семантика; полный список):**

- `run_first.py` — `RUN_NAME` → `run_K0-M3_101_v32`;
- тесты: `test_channel.py`/`test_session.py` — ожидания v32;
  `tests/test_transition.py` — T1 обновлён под привязку, добавлены T1-отрицание и
  T4 (проба по клетке H1); R1–R4 — без изменений;
- `admission_checks.py` — добавлены V32/V32-P/V32-S; **V31-S переведён на
  замороженную пару v30↔v31** (инвариантность, по образцу V28-P/V29-P-фиксов);
  A20 → v32; числа диффа промптов в V32-P сверены и зафиксированы (+8/−7) —
  нюанс вычисления пойман проверкой допуска до публикации;
- фрозен-копии `version-history/K0_PROMPTS_v31.py`, `K0_SESSION_v31.py`,
  `K0_CALLS_v31.py`; диффы: протокол, промпты, сессия, calls.

**Сознательно НЕ включено:** изменения механизма вердиктов и `DECISION`;
автопреобразование повторной регистрации в действие; правки подсказки dup-отказа и
строки меток (кандидаты следующих итераций).
