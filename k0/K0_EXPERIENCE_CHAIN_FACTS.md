## 1. Механика, релевантная вопросам (§3, §5, §7 протокола v28)

- Проба исполняется по текущему состоянию объекта `o`:
  - `o` = present → «раскрытая»: исход клетки получен; строка `O T H -> исход`
    появляется в наблюдениях агента (`[ТВОИ НАБЛЮДЕНИЯ]`) в следующих вызовах;
  - `o` = disappeared → «маскированная»: исход клетки НЕ получен; в наблюдения
    агента строка НЕ добавляется (в журнале `masked=true, revealed=false`).
- Журнал каждого исполнения: `prediction_pre` → `action_requested` (P<n>) →
  `probe_outcome` → `budget`; переход объекта — отдельная запись `state_change`
  (в контекст агента как «смена состояния» не транслируется).
- Контекст F2 у агента: только раскрытые наблюдения, `[ПОСЛЕДНЯЯ ПРОБА]`
  (клетка), `[МЕТКИ]` (P=n), бюджет. **Обязательной точки обновления гипотез
  норма НЕ содержит:** Q/H/VERDICT/DECISION — доступные, но не обязательные
  конструкции; при использовании обязательны правила привязок (§7), а
  `AFTER P<n>` вердикта обязан ссылаться на пробу, исход которой РАСКРЫТ агенту.

## 3. Ответы на вопросы аудита — факты

**3.1. Почему выбирал повторы.** 10 из 16 действий — `repeat`; отказов нет
(`malformed=0`, `rejections=[]`); предсказание каждый раз фиксировалось заново
(§3 протокола). Траектория: P3–P4 — повтор клетки P2 (O1 T=0 H=2); P9–P16 —
повтор клетки P8 (O4 T=1 H=0), восемь раз подряд. Нормой повторы не ограничены;
механических преград нет. Причина выбора — поведение модели (наблюдение, не
норма); интерпретаций здесь не делается.

**3.2. Что получал в контексте после раскрытия исходов.** Только раскрытые
наблюдения (список растёт, дубликаты сохраняются: три строки `O1 T=0 H=2`),
`[ПОСЛЕДНЯЯ ПРОБА]`, `[МЕТКИ]`, бюджет. Проверка реконструкцией: промпты
пересобраны из сохранённых контекстов (`raw/calls/*.request.txt`) для вызовов
0008–0011; пример — вызов 0009 (после P7): наблюдений 6 строк (P7 отсутствует),
`[ПОСЛЕДНЯЯ ПРОБА] O3 T=1 H=0`.

**3.3. Были ли доступны сведения об изменении состояния.**
- Записи `state_change` в контекст агента не транслируются.
- Доступный агенту сигнал: раскрытая проба P5 добавила строку
  `O3 T=2 H=0 -> disappeared`; строка присутствует во всех контекстах вызовов
  0007–0017 (её видно при выборе P8–P16).
- Прямой повтор той же клетки (P7, O3 T=1 H=0) оказался МАСКИРОВАННЫМ: исход
  агенту не раскрыт и ни в одном последующем контексте не появляется.
- На момент выбора P8–P16 в контексте: один факт «disappeared» по O3 (P5, T=2),
  один безрезультатный (маскированный) тест O3 T=1 H=0, и раскрытые present-факты.

**3.4. Обязательная точка обновления гипотез.** В норме v28 ОТСУТСТВУЕТ (F2 —
свободная фаза; Q/H/VERDICT/DECISION не обязательны). Дополнительно: вердикт
`AFTER P<n>` обязан ссылаться на раскрытый исход; маскированная проба P7 для
вердикта непригодна по норме.
