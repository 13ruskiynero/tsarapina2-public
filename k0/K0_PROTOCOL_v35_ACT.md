# K0 — АКТ v35-A: переход «принятый вердикт → DECISION» (секция `[РЕШЕНИЕ]`)

Дата: 2026-10-17 · Подготовил: DeepSeek TUI · Для постановщика K0 и внешней проверки
Статус: **v35-A подготовлен; проверки пройдены; публикуется ДО запуска.
Запуск НЕ ВЫПОЛНЕН и будет выполнен только по отдельному явному разрешению
после ревью (без повторов, правок по ходу и автоперезапусков).**
v26–v34 и их артефакты — заморожены.

Решение постановщика от 2026-10-17 (фрагменты дословно):

> модель или критерии принятия.

Уточнение по среде (по вопросу о сиде): «**сид 101 (как в v34)**»; «K0-M3/102» —
серийный номер второго запуска серии. Среда — замороженная `history_101`
(sha256 `7c1587a7…5cbf`), та же, что в v34: единственная переменная — секция
`[РЕШЕНИЕ]`.

## 2. Изменение (единственная семантическая правка)

**`prompts.py`** — секция `[РЕШЕНИЕ]` в F2-промпте, видимая при следующем вызове
**после принятого вердикта** и **до первого принятого `DECISION`**:

    [РЕШЕНИЕ] Вердикт {V}: гипотеза {H} {опровергнута|подтверждена} после пробы
    {P}. Прогноз {pred} для клетки {cell} {не подтвердился|подтвердился}:
    результат пробы — {outcome}. При следующем действии укажи DECISION с USING
    {V}. Затем укажи PREDICT для выбранной клетки и ACTION.

- Строится из записи реестра (V, H, P, клетка, прогноз, исход, resolution);
  **не выбирает за модель следующую клетку** и не вычисляет решение.
- До вердикта секции нет; для маскированных проб секции нет (вердикта нет);
  после принятого решения секция исчезает; вне F2 отсутствует.
- Грамматика и валидатор решений (`DECISION: <дескриптор> USING V<n>` — существующий
  вердикт + тот же дескриптор действия) **не изменяются**; мир, батарея, модель и
  критерии принятия — не изменяются.
