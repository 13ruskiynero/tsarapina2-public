# K0 — КРИТЕРИЙ РАЗЛИЧЕНИЯ H3 vs H2 (проект, для согласования)

Дата: 2026-10-17 · Подготовил: DeepSeek TUI · Для постановщика K0 и внешней проверки
Статус: **проект критерия; НЕ дизайн эксперимента; код и протоколы не менялись;
модель не вызывалась; v36-A и предыдущие комплекты не трогаются.**

## 1. Гипотезы (операционально)

- **H3 — неопределённость следующей цели.** После принятого вердикта V1 и
  исполненного решения (P2) у агента нет открытой исследовательской цели; если
  цель определить явно, модель способна продолжить корректным действием, не
  возвращаясь к повторной регистрации Q1/H1.
- **H2 — зацикливание регистрации.** Повторная регистрация Q1/H1 — устойчивый
  поведенческий паттерн, не зависящий от наличия цели: наличие открытой цели
  цикл не прекращает.

## 2. Условие проверки (что именно варьируется)

- В состоянии присутствует **открытая цель**: ≥1 зарегистрированная гипотеза без
  вердикта (например, Q2/H2 со своей клеткой и прогнозом), видимая агенту в
  контексте (список гипотез / метки). Способ появления цели (с начала прогона
  или после P2) — предмет дизайна; критерий от способа не зависит.
- **Запрещено в рамках этого критерия:** любые новые инструкции или секции
  промпта, называющие клетку, объект, тип действия или формат блока; изменения
  валидатора и грамматики; изменение окна отказов; изменение лимитов и
  параметров модели.
- Всё остальное (мир, история, батарея, сид, модель) — как в v36-A.

## 3. Наблюдаемые величины (в окне W)

Окно **W** — первые **5 вызовов**, в контексте которых открытая цель видна И
предыдущее исполненное действие завершено (P2). Достаточность данных: **≥3
вызова** с видимой целью; меньше — неинформативно.

- **O1.** Валидный блок действия: отдельная строка `PREDICT` + `ACTION`, принят
  существующим валидатором.
- **O2.** Исполненная проба и её клетка.
- **O3.** Повторные попытки регистрации Q1/H1 (число пар) в окне.
- **O4.** Новые цели, предложенные моделью (попытки Q2/H2 и далее).

## 4. Решающая таблица (предрегистрированная)

| Наблюдение в окне W | Классификация |
| --- | --- |
| O1 есть; O2 — клетка = клетка открытой цели; O3 = 0 | **H3 поддержана**: цель доступна → корректное продолжение; H2 не требуется для объяснения |
| O1 есть; O2 — клетка ≠ цели; O3 = 0 | **H3 частично**: цель сняла блок «действия», но не «следования цели»; H2 остаётся жизнеспособной; нужен отдельный различающий шаг |
| O1 нет; O3 > 0 (цикл продолжается) | **H3 не поддержана; H2 остаётся жизнеспособной**: наличие цели не снимает цикл |
| O1 нет; O3 = 0; O4 > 0 | **Неинформативно для H3/H2** (смена поведения без действия); фиксируется отдельно |
| Прогон остановлен до окна / цель видна < 3 вызовов | **Неинформативно** (предусловия не выполнены) |

## 5. Что инвалидирует тест

- любая подсказка клетки, формата или типа действия (критерий начинает
  проверять подсказку, а не H3);
- изменения валидатора, грамматики, лимитов, окна отказов;
- правки по ходу, повторные запуски, изменения артефактов задним числом.

## 6. Границы вывода

- «H3 поддержана» = в данном сценарии наличие открытой цели достаточно для
  корректного продолжения. Это не доказывает общий механизм «понимания цели» и
  не исключает H2 как привычку в других состояниях.
- «H3 не поддержана» = цель недостаточна в этом сценарии; H2 остаётся
  жизнеспособной, но H3 не опровергнута окончательно (возможное ограничение —
  недостаточная «видимость» цели; фиксируется).
- Ни один исход не доказывает «обучение» или «пересмотр убеждений».
